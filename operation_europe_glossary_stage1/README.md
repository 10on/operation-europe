# Operation Europe — Stage 1 source pack

Этот архив — пакет источников и техническое задание на первый этап: глоссарий и описание интерфейса Sega Mega Drive / Genesis.

- `SOURCES.md` — проверенные ссылки и приоритеты.
- `AGENT_TASK.md` — задача агентам, форматы результата и критерии готовности.

Полные сторонние FAQ и сканы мануалов в архив не вложены из-за ограничений на распространение; агенты должны читать их по ссылкам.
