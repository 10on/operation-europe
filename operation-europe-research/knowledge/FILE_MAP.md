# Файловая карта шести сценариев

Все смещения и размеры — десятичные file offsets от начала файла. Строки N — число Down в меню.
Источник: main.exe SHA-256 `0b33be2fd37b965e5b92d1881f34226c1608eff6d0358787a7cb5049f218e9df`; SCEDATA SHA-256 `a213bdfb541780259bdf789b514896fa4f1278c826f789206bbb0d17d1355936`.

## Метод и границы

BPINT 21h/AH=3Dh,3Fh,42h,3Eh с начала MAIN; результат снят до следующей инструкции по CS:IP+2. Позиция ведётся отдельно для каждого handle, повторное открытие сбрасывает её. Каждое успешное ненулевое чтение сверено целиком с файлом и повторно проверено по SHA буфера.
Не охвачены запуск FMDRV до MAIN, create/extended-open, save/load и дальнейшая игра. Ввод, кадры и исходные регистры лежат рядом с JSONL. VGA-кадры восстановлены из четырёх плоскостей; палитра нейтральная, цвета не измерены.
Ограничение маршрута: AUTOTYPE продолжал посылать Enter после появления карты. Кадры показывают исполнение приказов и продвижение времени до нескольких часов; выбор One Player не подтверждён. Таблица включает все чтения за 190 секунд, в том числе после загрузки карты. Точная остановка на первом готовом стратегическом экране ещё не реализована. Флаг complete=false в исходных summary.json был не обновляемым полем ранней версии сборщика; завершение всех шести интервалов проверено по elapsed_s=190 и session.json.

## Артефакты и повторение

Пакет: `artifacts/experiments/IOLOG-20261031/batch/scenario-N/io.jsonl`; сводка и хеши кадров: `artifacts/experiments/IOLOG-20261031/batch/verified.json`.
`oe-iolog --all --seconds 190 --out <новый каталог>`; затем `python scripts/oe_file_map.py <каталог>`. Нужны DOSBox-X с native debugger API и Pillow.

Всего: 466 операций, 163 чтений, 1515358 байт; расхождений буферов — 0. Confidence: observed для этих запусков.

## Структурный парсер

`scripts/scedata_record.py`: 12×800 байт + 7×8143 байт; round-trip всего файла и каждой записи побайтно равен. Шесть выбираемых записей имеют offsets 17743…58458; запись offset 9600 в этих шести загрузках не выбрана. Смысл большей части полей остаётся unknown; парсер сохраняет их как opaque bytes, календарь +2…+6 — только кандидат.
