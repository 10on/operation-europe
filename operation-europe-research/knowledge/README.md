# Knowledge base

Проверяемые находки и текущие гипотезы. Все данные требуют source hash, адреса/смещения, метода проверки и статуса confidence. Состояние стенда — `STATE.md`; первые файловые измерения — `DATA_FILES.md`; проверенные точки DOS file open — `FILE_IO.md`. Локальные подробные доказательства находятся в игнорируемом Git каталоге `artifacts/experiments/`.
