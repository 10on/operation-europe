# Формат сохранения `SAVEDATA` (DOS-версия)

Файл `SAVEDATA` в каталоге игры создаётся при первом сохранении. Размер всегда 202 420 байт: 20 заголовков по 12 байт и 20 слотов по 10 109 (0x277D) байт.

- Парсер и писатель: `scripts/savedata_record.py`. Метод `with_bytes` правит слот, переносит дату в заголовок и пересчитывает контрольную сумму.
- Тест: `tests/test_savedata_record.py`. Синтетические случаи и round-trip локального сейва: SHA-256 `7998a5ea…`.
- Эксперимент: `artifacts/experiments/SAVE-222-20261103/` (локально). Сейвы и игровые данные в git не входят.

Статусы: `confirmed` — код и рантайм или эксперимент с изменением значения; `observed` — измерено; `inferred` — вывод; `unknown` — не установлено.

## Код

Адреса в Ghidra; файловое смещение = (seg−0x1000)·16 + off + 0x6000.

| Функция | Ghidra | Назначение | Статус |
|---|---|---|---|
| сохранение | 3597:091e | Если файла нет, вызывает 3597:0794. Иначе читает 20 заголовков в DS:D006, ждёт выбор слота DS:E2F4, затем пишет заголовок по `слот·12` и слот по `0xF0 + слот·0x277D` из DS:0x42 | `confirmed` (код + сейв в DOSBox) |
| создание файла | 3597:0794 | Создаёт `Savedata` (DS:B055). Пишет 20 заголовков (у слотов 1..19 байт 0 = 6) и 20 копий DS:0x42..0x27BE | `confirmed`: в первом сейве 19 пустых заголовков и 20 одинаковых слотов |
| указатели → индексы | 3597:04d2 | Перед записью ближние указатели заменяются номерами записей (0xFFFF = NULL). После записи 3597:0218 возвращает их обратно | `confirmed` (код; контрольная сумма сходится) |
| загрузка | 16db:081c | Открывает `SAVEDATA` (DS:4560), читает заголовки, выбор слота, seek `0xF0 + слот·0x277D`, читает 0x277D байт в DS:0x42 | `confirmed` (код + загрузка изменённого сейва) |
| индексы → указатели | 16db:00b4 | Обратное преобразование | `confirmed` (код) |
| проверка суммы | 16db:07c6 (запись 3597:0752) | 16-битная сумма байтов DS:0x42..0x27BE после восстановления указателей = слово заголовка +10. При несовпадении или при байте 0 = 6 слот не загружается | `confirmed`: сумма воспроизводится; сейв с пересчитанной суммой загружен |

## Заголовок слота (12 байт, по смещению `слот·12`)

| Смещение | Поле | Источник | Статус |
|---|---|---|---|
| +0 | селектор сценария; 6 = пустой слот | DS:0x43 (scedata +1) | `confirmed` (код; в списке загрузки «France») |
| +1 | байт | DS:0x4B | `observed` = 0; смысл `unknown` |
| +2..+4 | год−1940, месяц, день | DS:0x44..0x46 | `confirmed`: день 10→12 показан в списке как «5/12/40» |
| +5 | час | DS:0x47 | `confirmed`: 0→6 показан как «6H» |
| +6..+7 | слово | DS:0x5E | `observed` = 0; вероятно, сложность (V.Easy) — `inferred` |
| +8..+9 | слово | DS:0x60 | `observed` = 1; вероятно, сторона игрока (Allies = User) — `inferred` |
| +10..+11 | контрольная сумма | расчёт | `confirmed` |

## Слот (10 109 байт) = DGROUP DS:0x42..0x27BE

Байт слота k соответствует DS:(0x42 + k).

| Диапазон DS | Содержимое | Статус |
|---|---|---|
| 0x0042..0x2010 (8143 байт) | запись сценария scedata (`docs/SCEDATA_FORMAT.md`) в текущем состоянии игры; при старте читается целиком в DS:0x42 | `confirmed`: трасса TASK-010 (scedata-read в DS:0x42, 8143 байт); 414 байт слота отличаются от записи 1 после старта |
| 0x0042 | тег 69 | `observed` |
| 0x0044..0x0047 | дата и час текущего хода | `confirmed`: изменение видно в игре («5.12.40 06:00») |
| 0x0142, 0x014F | 2 указателя на записи по 68 байт (DS:0x1A7C) | `confirmed` (код) |
| 0x021A + i·0x41, i=0..1 | 2 записи по 65 байт; при байте +0x3F > 7 по +0x17/+0x1B/+0x1F лежат указатели на 68-байтные записи | `confirmed` для типа > 7 (в сейве 255); ветки 0..7 `unknown` |
| 0x053A.. | командир армии игрока: +0 Leader, +1 Charm, +2 Bravery, +3 Health, +4 Exp(?), +5 Inf, +6 Arty, +7 Tanks | `confirmed` для Leader (67→99) и Tanks (26→77); остальные `observed` (совпадают с экраном) |
| 0x07FC..0x14FB | 256 записей по 13 байт; слово +0 — указатель на 13-байтную запись | `confirmed` (код) |
| 0x14FC..0x1A7B | 64 записи по 22 байта; слово +0 — указатель на 13-байтную запись; слова +0xC/+0x10 — указатели на 22-байтные записи при байте +0xE/+0x12 ∈ {2,9,11,12} | `confirmed` (код) |
| 0x1A7C..0x2051 | 22 записи по 68 байт | `inferred` (база и шаг из кода; число — до 0x2052) |
| 0x2011..0x27BE (1966 байт) | состояние вне записи scedata | `observed`; содержимое `unknown`, кроме строк ниже |
| 0x2052..0x20A5 | 42 указателя на 68-байтные записи | `confirmed` (код) |
| 0x20A6..0x20B5 | 8 указателей на 22-байтные записи | `confirmed` (код) |

Шаги 13, 65 и 68 совпадают с массивами, найденными в хвосте записи scedata (#221). Смысл записей нужно разбирать в #221.

Суммы армии на экране (Tanks 217, Infntry 12811 и т. д.) в слоте не хранятся, они вычисляются.

## Проверка изменением значения (SAVE-222-20261103)

1. Новая игра «France», Allies, V.Easy; Game → Save / Quit → Save Game. Получен `save-a-5.10.40.bin`.
2. `with_bytes(0, {0x46: 12, 0x47: 6, 0x53A: 99, 0x541: 77})`. Получен `save-b-edited.bin`, записан в рабочую копию.
3. Game → Load/New Game → Load Game → No. 1.
   - Список загрузки: «5/12/40 6H».
   - После загрузки: «5.12.40 06:00», Leader 99, Tanks 77.
