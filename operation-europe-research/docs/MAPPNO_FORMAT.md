# Формат `mappno.dat` (DOS-версия)

Файл: 9600 байт, SHA-256 `12c45df5…3d81cc3e9` (рабочая копия, в git не входит). Парсер/писатель: `scripts/mappno_record.py` (та же разметка, что у `mapinf.dat`, см. `docs/MAPINF_FORMAT.md`); тест: `tests/test_mappno_record.py`. Анализ: `artifacts/experiments/MAPPNO-FMT-20261103/` (локально).

| Поле | Смещение / размер | Статус | Основание |
|---|---|---|---|
| Регион i | `i·1600`, 1600 байт, i=0..5 | `observed` | runtime-лог чтений: по одному чтению 1600 байт с `i·1600` на сценарий (IOLOG-20261031, `knowledge/FILE_MAP.md`) |
| Сетка | 40 × 40 байт | `inferred` (слабо) | сходство по вертикали при ширине 40 — 0.24, при 20/80 — 0.09/0.20; совпадает с разметкой mapinf |
| Значение клетки | 1 байт, 0..79 (в регионе до 80 разных) | `observed` (диапазон), смысл `unknown` | гистограмма; значения не образуют связных областей (не номера провинций) |
| Ноль | значение 0 | `observed`: клетки с 0 почти всегда имеют код mapinf 3 | сравнение с `mapinf.dat` по тем же индексам |

Гипотеза (не проверена): номер узора/тайла для отрисовки клетки. Проверка — изменение значения в рабочей копии и сравнение экрана.
