# Файлы картинок `scesel.dat`, `event.dat`, `sceend.dat`

Все три файла — наборы сжатых 16-цветных картинок, каждая начинается с границы 512-байтного сектора. Здесь разобрана только структура (заголовок, таблица цветов, длина потока команд). Декодирование пикселей относится к графике (M11).

- Парсер и писатель: `scripts/koei_pic.py`. `SectorFile.parse(...).build()` возвращает файл байт в байт.
- Тест: `tests/test_koei_pic.py`. Синтетические случаи и round-trip рабочей копии (пропускается без `private/`).
- Эксперимент: `artifacts/experiments/PICFILES-20261103/` (локально): таблица картинок `pictures.json`.

Статусы: `confirmed` — код и round-trip; `observed` — измерено; `inferred` — вывод; `unknown` — не установлено.

## Код

Адреса в Ghidra; файловое смещение = (seg−0x1000)·16 + off + 0x6000.

| Функция | Ghidra | Назначение | Статус |
|---|---|---|---|
| seek | 1a04:016c | Смещение в файле = BX·512 (BX — номер сектора), хэндл в DS:0x2F6E | `confirmed` (код) |
| показ с таблицей | 1a04:01ce → 1000:3490 | Декодер с таблицей цветов (DS:0x3EB6 = 1, литералы 1000:334e) | `confirmed` (код) |
| показ без таблицы | 1a04:01a0 → 1000:34a4 | Декодер без таблицы (DS:0x3EB6 = 0, литералы 1000:3320) | `confirmed` (код) |
| декодер | 1000:30a6 | Читает поток через far-callback [BP+0xA], пишет в VGA (планарный режим) | `confirmed` (код) |
| выбор сценария | 16db:1700 | Сектор картинки scesel = слово DS:0x4F50 + селектор·2: 29, 29, 44, 51, 65, 76, 91; заставка — сектор 0 | `confirmed` (код + IOLOG чтения по 14848…46592) |
| финал | 190d:0126 | sceend: сектор 27, 80, 147 или 217 (выбор по DS:0x2F82 и DS:0x5A[...]; смысл условий — `inferred`: сторона/исход) | `confirmed` (код) |
| событие | 2707:03e4 | event: сектор из AX; в коде сравнение с 0xE7 = 231 | `confirmed` (код) |

## Картинка

| Смещение | Поле | Статус |
|---|---|---|
| +0 | слово ширина, 1..640 (декодер проверяет) | `confirmed` |
| +2 | слово высота, 1..400 | `confirmed` |
| +4 | только в режиме с таблицей: 8 слов таблицы цветов (каждое слово — 4 пикселя по 4 бита) | `confirmed` (код); смысл слова — `inferred` |
| далее | поток команд, h строк, в строке (w+3)/4 ячеек по 4 пикселя | `confirmed` (код + все картинки кончаются внутри своего сектора) |

Команды (байт b; count — число ячеек):

| b | Длина | count | Смысл | Статус |
|---|---|---|---|---|
| 0x80..0xBF | 1 | (b & 0xF) + 1 | копия из той же строки левее на ((b>>4)&3)+1 ячеек | длина `confirmed`, смысл `inferred` |
| 0xC0..0xFF | 1 | (b & 0xF) + 1 | копия из строк выше (сдвиг ((b&0x30)+0x10)·10) | длина `confirmed`, смысл `inferred` |
| < 0x80, без таблицы | 2 | ((b>>4)&7) + 1 | узор из (b&0xF)<<8 \| следующий байт | длина `confirmed`, смысл `inferred` |
| < 0x80, с таблицей, (b&0x78)=0 | 1 | (b & 7) + 1 | нулевой узор | `confirmed` |
| с таблицей, b&0x40 | 1 | (b & 7) + 1 | элемент таблицы (b>>3)&7 | `confirmed` |
| с таблицей, (b&0x78)=0x38 | 3 | (b & 7) + 1 | узор — следующие 2 байта | `confirmed` |
| с таблицей, прочие | 2 | (b & 7) + 1 | узор из следующего байта, 6 способов раскладки (таблица 1000:3342) | длина `confirmed`, раскладка `inferred` |

Строка кончается, когда сумма count достигает числа ячеек (лишнее отбрасывается).

## Файлы

| Файл | Размер, SHA-256 | Режим | Картинки | Остаток | Статус |
|---|---|---|---|---|---|
| scesel.dat | 53 760, `e2b05498…` | с таблицей | сектор 0: 640×400 (экран выбора); 29, 44, 51, 65, 76, 91: 256×128 (по сценарию) | секторы 103–104 (1024 байт) без заголовка картинки, похоже на 1-битные маски | картинки `confirmed`; остаток `unknown` |
| event.dat | 261 120, `4dc686d0…` | без таблицы | 33 картинки, в основном 256×168, есть 640×100 | нет | `confirmed` (round-trip); назначение отдельных картинок `unknown` |

Байты между концом картинки и следующим сектором ненулевые (остатки сборки). Писатель хранит их как есть: `observed`.

Неграфических данных событий (условий, текстов) в event.dat нет: файл целиком покрыт картинками. `confirmed` (round-trip без остатка).
