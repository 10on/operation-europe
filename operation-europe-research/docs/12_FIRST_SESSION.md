# 12. Чеклист первого исследовательского сеанса

Этот документ можно целиком скопировать локальному Windows-агенту после установки среды. Для отсутствующих файлов — не придумывать результат.

## 0. Проверить входы

- [ ] Дистрибутив DOS находится в `private/game-dos/`, SHA-256 ещё не изменён.
- [ ] Есть копия `private/game-dos-working` для эмулятора.
- [ ] Список ПО и версии сохранены в `knowledge/ENVIRONMENT.md`.

## 1. Сделать inventory

```powershell
cd C:\OE
py -3 scripts\inventory.py private\game-dos --out artifacts\inventory.json
```

Проверить parser warnings, содержимое каталога, количество файлов, MZ-сигнатуры и возможные overlays; **не** назначать главный бинарник по имени файла, пока не видно запуска.

## 2. Первый запуск

Настроить конфиг DOSBox Automation, монтирование *копии* игры, выполнить `status`, `info`, `screenshot`. Зафиксировать, чем запускается игра; не включать автоматический бот/AI до ручной проверки одного перехода меню. Если `video/text` не используется или пуст — это нормально при графическом режиме.

## 3. Ghidra

Импортировать 1 файл, проверить x86 real mode и entry point, получить screenshot и список entry, сегментов, функций. Не делать сразу огромных экспортов C псевдокода. При большом хвосте или невалидном entry записать возможную упаковку/оверлей, не пытаться угадывать алгоритмы.

## 4. Проверка GUI поля

Ручной/автоматизированный агент открывает один экран характеристик, сохраняет PNG до/после, указывает ROI и текст **только для читаемых полей**. Mac может прогнать Vision как отдельную задачу. Записать 1–3 параметра в `observations.json`.

## 5. Результат и остановка

Результат первой сессии — **набор честных фактов**, не декомпилированная игра. Требуется:

- `artifacts/inventory.json`;
- `knowledge/ENVIRONMENT.md`;
- `artifacts/experiments/EXP-001/before.png`;
- `artifacts/experiments/EXP-001/report.json`;
- список неизвестных вопросов и приоритет следующего опыта.

Если исполняемый файл не предоставлен, отчёт должен говорить `BLOCKED: original DOS distribution not present`; это правильная, а не провальная сдача задачи.
