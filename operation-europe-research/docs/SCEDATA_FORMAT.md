# Формат `scedata` (DOS-версия)

Файл: `scedata`, 66 601 байт, SHA-256 `a213bdfb…1355936` (рабочая копия `private/game-dos-working/scedata`, в git не входит).
Парсер/писатель: `scripts/scedata_record.py` (классы `Scedata`, `Record`); тест: `tests/test_scedata_record.py` (round-trip даёт тот же SHA-256; синтетические случаи без игровых данных).
Анализ полей: `artifacts/experiments/SCEFIELDS-20261103/` (локально).

Статусы: `confirmed` — код/рантайм + независимая проверка; `observed` — измерено в рантайме или в байтах; `inferred` — вывод из закономерностей; `unknown` — не установлено.

## Раскладка файла

| Смещение файла | Размер | Поле | Статус | Основание |
|---|---|---|---|---|
| `0 + N·800`, N=0..11 | 12 × 800 | текстовые блоки (ASCII, TAB/CR/LF, нулевой хвост) | `confirmed` (границы) | runtime-чтения по `N·800` длиной 800 (TASK-011); round-trip |
| блоки 0..5 | 800 | предыстории сценариев | `observed` | TASK-011/019/021: блок читается и передаётся в текстовый поток |
| блоки 6..11 | 800 | условия победы | `inferred` | по содержимому; чтение кода не прослежено |
| `9600 + i·8143`, i=0..6 | 7 × 8143 | записи сценария | `confirmed` (границы) | runtime-чтения 8143 байт по 17743/25886/34029 (TASK-010/014/015); round-trip |

Пункт меню N (0..2) читает запись `9600 + (N+1)·8143` (`observed`, TASK-010/014/015). Запись 0 по заголовку дублирует запись 1 (та же дата, селектор 128 вместо 0) — `observed`; её роль `unknown`.

### Массивы записи (#221)

Запись читается в DS:0x42, поэтому DS = смещение в записи + 0x42. Базы и шаги массивов взяты из кода сохранения: 3597:04d2 заменяет указатели индексами, 16db:00b4 восстанавливает их (см. `docs/SAVEDATA_FORMAT.md`). Доступ — `Record.array(name)`, `city()`, `division()`, `regiment()` в `scripts/scedata_record.py`.

| Массив | Смещение в записи (DS) | Элемент × число | Конец | Статус границ |

| стороны | +0x01D8 (DS:0x21A) | 65 × 2 | +0x0259 | `confirmed` (код) |
| офицеры | +0x025A (DS:0x29C) | 31 × 44 | +0x07AD; +0x07AE..+0x07B9 не разобраны | база `observed` (имена с шагом 31; в записи 0 они отличаются именно на этих местах), число `inferred` |

- Оригинальные данные и фрагменты текстов не коммитятся; в отчётах — только смещения, размеры, хеши.
- Изменение полей для проверки — только в `private/game-dos-working/`, мастер-копию не трогать.
